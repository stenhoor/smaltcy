# Other functions

Functions that don't belong to a kind above.

## Functions {#functions}

- [`coalesce`](./coalesce): The first argument that isn't `null`, or `null` when they all are.
- [`exists`](./exists): True when a property is there (isn't `null`). `exists(n.key)` is `n.key IS NOT NULL`.
- [`timestamp`](./timestamp): The time now, in milliseconds since 1970 (UTC).
